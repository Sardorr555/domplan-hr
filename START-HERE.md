# DOMPLAN HR — запуск без Docker

1. Откройте `D:\pta\domplan HR` и запустите **Start-HR.cmd** двойным щелчком. При первом запуске нужен интернет для установки Python-пакетов. Python уже установлен на этом компьютере.
2. Оставьте окно сервера открытым. Перейдите в браузере на **http://127.0.0.1:8000**.
3. В отдельном окне запустите **Create-Demo-Accounts.cmd**. Сохраните выведенные пароли в защищённом месте. Аккаунты: manager@demo.local, hr@demo.local, ceo@demo.local, accountant@demo.local, superadmin@demo.local. Существующие пароли не меняются.
4. Для остановки нажмите **Ctrl+C** в окне сервера. Следующий запуск — снова Start-HR.cmd.

Вместо отдельных серверов используется Python/FastAPI и SQLite: база — файл `data\hr.db`. Docker, WSL и PostgreSQL для этого режима не нужны. SQLite подходит для небольшого локального использования; при расширении команды можно подключить PostgreSQL через DATABASE_URL без изменения интерфейса. Все роли, согласования, история и расчёты доступны в локальном режиме.

## RAGFlow

При первом запуске создаётся `.env`. Уже указан адрес:

```ini
COOKIE_SECURE=false
RAGFLOW_URL=https://api.swipies.app
RAGFLOW_API_KEY=
RAGFLOW_DATASET_ID=
```

Позже заполните API key и dataset ID, затем перезапустите сервер. Не отправляйте ключ в чат. Адрес должен предоставлять RAGFlow HTTP API по пути `/api/v1/datasets/...`. Если Swipies использует собственный формат API или другой путь, потребуется его спецификация; совместимость пока не подтверждена. Никакие HR-документы при настройке автоматически не отправляются.

`run.py` читает `.env` как текст и не исполняет его. Уже установленные переменные окружения имеют приоритет. По умолчанию сайт доступен только на этом компьютере, без внешней публикации.

## Проверка вручную

```powershell
.\.venv\Scripts\python.exe run.py --check
.\.venv\Scripts\python.exe -m pytest -q
```

Без изолированной среды, если зависимости уже установлены: `python run.py --check`, `python run.py --seed`, `python run.py`.

Для резервной копии остановите сервер и скопируйте всю папку `data` в защищённое место. Не удаляйте её при обновлении. Настройки находятся в `.env`; не публикуйте его.

Денежные переводы не выполняются: бухгалтер записывает подтверждение выплаты, сделанной вне системы.
